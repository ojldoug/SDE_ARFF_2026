## Important discrepancies and limits

- Historical Table 2 includes four methods for ex1,2,4,5,6,7, but only ARFF and shallow tanh for ex3. Modern width-matched two-layer MLP is not automatically the historical shallow/deep baseline.
- Historical symmetric Adam returns LLᵀ as sigma and uses Sigma=(LLᵀ)^2. Modern accepted Adam uses L as sigma and Sigma=LLᵀ. Both are SPD parametrizations; changing one to the other is not required merely to enforce SPD. This difference is a method-definition issue, not a stale learning-rate setting.
- Historical Adam source returns the final epoch, while historical tables summarize minimum validation losses. Modern accepted code retains the earliest minimum-validation checkpoint. A consistent artifact must identify the actual selected model; do not pair minimum loss with last-epoch RMSE.
- Historical ARFF stops using a five-point moving average with patience 5 and zero-based i > M_min, checks stopping before candidate retention, and truncates saved histories with [:i]. Current validated fitter uses one-based iteration > M_min, retains the current candidate first, and saves complete histories. The ex8 equality M_min=M_max avoided this early-stopping discrepancy. It matters for historical M_min < M_max.
- The fixed canonical 80/10/10 split and seed2026 are reusable reproducibility infrastructure, but differ from the active manuscript 90/10 description. Surviving notebooks also reshuffle outer splits per repetition. Record the correction rather than claiming exact historical splitting.
- SIR primary PDF Table1 says 99750 rows; Table8 says approximately22664. Correct fixed-lag canonical data has99719 rows with absorbing starts removed. Rows should not be trimmed to force either historical count.
- Ex6 draw laws are recovered: independent array draws W0~N(0,Δ²), Wj~N(0,2Δ²). Reformulation yields interior effective sigma=g/2, not g. The existing truth function correctly uses g/2, but its stored x/h labels do not consistently match the scheme.
- PDFs state fine-step EM with1000 steps, not an exact frozen one-step conditional Gaussian. Interpret NLL as quasi-likelihood and coefficient discrepancies as including finite-lag effects.
- Historical trajectory initial law, horizon, EM step, trajectory count, binning, seeds, and covariance treatment remain unrecovered. Do not invent a Fig.6 replication protocol.
- Raw covariance RMSE must remain distinct from SPD-projected likelihood/simulation covariance. Retain all runs regardless of raw SPD violations or test performance.
- GPU parallel timings cannot support isolated runtime claims. No isolated timing dispatch has occurred during this audit.
