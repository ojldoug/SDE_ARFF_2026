# Sources and distribution boundary

Consulted official Binance public-data README, data.binance.vision, developer Spot Product Terms page and linked Binance Terms page (28 September2026). README describes public downloads and states MIT for the repository. This is not treated as a verified grant to redistribute raw market archives. The product page points to general terms; the retrieved general page did not provide an unambiguous archival-data redistribution grant. Raw archives, price/return arrays and full prediction arrays will remain local, outside Git. Publish the original downloader, URLs/checksums and compact derived research reports, not an invented dataset license/download mirror. No API credentials or account are used. No legal permission beyond the public-access/source documentation is asserted.

- https://github.com/binance/binance-public-data : schema,2025 microsecond change, CHECKSUM and revision warning. Snapshot sources/binance_README.md.
- https://data.binance.vision/ : official archive.
- https://developers.binance.com/en/docs/products/spot/PROD-TERMS-OF-USE and https://www.binance.com/en/terms : terms consulted via browser; local HTML request returned empty and is not claimed as a complete terms archive.
- Engle(2002), https://doi.org/10.1198/073500102288618487 ; author manuscript https://pages.stern.nyu.edu/~rengle/dccfinal.pdf, equations(21)–(23), two-step likelihood estimation. Primary PDF retained locally; not redistributed in Git.

No raw data or publication PDFs need to be committed. Copyright/availability of third-party sources are distinct from this repository's code licensing.
