| File | Purpose |
|---|---|
| PROTOCOL.md, JOB_MANIFEST.json, FROZEN.json | Before-fitting design, all18candidate fits, source/data hashes |
| DATA_MANIFEST.json, initial_timestamp_failures.json, DATA_PREFLIGHT_NOTE.md | Official147archive identities, incomplete-hour exclusion evidence |
| SPLIT_MANIFEST.json | Eligible counts and fitting-only feature/return normalization |
| PREFIT_CHECKS.json, PRETEST_GATE.json | Independent algebra/recursion/causality checks and sealed-test opening gate |
| candidate_validation.csv, checkpoint_summary.csv | Every configuration/seed and native selected iteration/loss |
| DCC_REPORT.json | All deterministic optimizer starts, failures, selected feasible parameters |
| SELECTION.json | One configuration per learned method selected by mean3seed validation NLL; EWMA selection |
| per_run.csv, summary.json | All selected-seed validation/test scores, SPD/projection and calibration |
| per_month.csv, paired_differences.csv | Temporal scores/coverage/counts and same-hour differences against three baselines |
| portfolio_scores.csv | Fixed equal-weight and BTC-ETH spread scalar scores/calibration |
| comparison.pdf, comparison.png | Compact score and monthly paired comparison |
| OUTPUT_VALIDATION.json | Final artifact identity, checkpoint and reporting audit; no inference |
| RUNTIME.json, ENVIRONMENT.txt, execution.json, WARMUP.json | Executed runtime, GPU/caches, measured resource use |
| ADDITIONAL_DEPENDENCIES.json | Transitive tracked-source imports unchanged from pre-run HEAD |
| PERSISTENCE_CHECK.json | Detached session independently observed after launch connection ended |
| COMPLETE.json or FAILURE.json/PARTIAL.json, status.json | Terminal scope and status |
| REPORT.md, FINAL_SUMMARY.txt | Scientific findings and inclusion recommendation |
| REPRODUCING.md, RIGHTS_AND_SOURCES.md, AI_ASSISTANCE.md | Commands, availability/licensing boundary and automated assistance disclosure |

Large/local generated inputs are retained but excluded from Git: `development_archives/`, `sealed_test_archives/`, `development.npz`, `models/*.pkl`, `selected_{validation,test}_predictions.npz`, `{validation,test}_score_arrays.npz`, timestamp CSVs, structural-timestamp arrays, source PDFs, cache directories and console logs. Individual model JSON envelopes are compact and included. Model inputs can be regenerated by the documented downloader/preprocessor if official archives remain available and their hashes still match. Exact historical selected forecasts require the saved model/forecast files; no public hosting is claimed.

The common evaluator is `scripts/financial_pilot/evaluation.py`. Financial execution is split into `download`, `data`, `checks`, `dcc`, `pipeline`, `freeze`, `supervise`, `report`, and the post-completion read-only `validate_outputs` audit. See FROZEN.json for exact executed hashes; `validate_outputs` was added after dispatch and cannot alter fits or model selection.

The companion colloidal correction is `../experimental_trajectory_evaluation_float64_v1/`; its summary records original raw-input hashes and its ORIGINAL_VALIDATION_RECORD.json preserves the original failed strict checks. Neither study modifies manuscript results.
