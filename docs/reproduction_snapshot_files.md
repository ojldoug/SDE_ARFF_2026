# Committed reproduction snapshot

This snapshot adds the reproduction source, tests, audits, final scientific reports, compact metric distributions, provenance and Manchester poster candidate figures listed below, in their existing directories. It does not change numerical settings or rerun experiments.

Large canonical datasets and per-seed model archives remain in the ignored `data/` and `results/production/` directories, unchanged and not uploaded by this commit. Root-level temporary console/diagnostic logs are deliberately untracked. Existing reference/source history is preserved.

Pre-commit review: initial `git status` showed only untracked additions; initial `git diff --check` passed. The staged whitespace check flags CRLF CSV endings, one pre-existing trailing-space line in audit_matrix.md, and terminal blank lines in two archived summary.txt copies. These accepted report bytes are intentionally preserved to retain their recorded checksums. All staged Python files parse; all staged JSON files parse; staged blobs match on-disk bytes. No training jobs were run for this commit.
